▤
개인 테스트용 안내 — 상품·콘텐츠·판매 데이터는 이 브라우저에만 저장되며 다른 기기와 자동 동기화되지 않습니다. AI 문체 추천은 WebGPU 지원 기기에서만 가능하며 최초 모델 다운로드에 많은 데이터와 메모리가 필요할 수 있습니다. 게시용 문구는 AI 원문을 그대로 사용하지 않고 입력 정보와 정해진 문장으로 구성합니다. 입력한 사실 자체는 직접 검토하세요. 로그인·결제 기능은 없고, 실제 고객 정보는 입력하지 마세요.

선택 기능 — 기기 내 AI 문체 추천

브라우저 AI는 문체만 선택합니다. AI 원문을 게시글에 직접 넣지 않으므로 임의의 출시일, 성능, 판매 실적이 추가되지 않도록 설계했어요. 상품 정보 자체는 직접 확인해 주세요.

📝 저장된 콘텐츠

보관된 콘텐츠가 없습니다.

콘텐츠는 인스타그램·블로그·쇼츠 글 3개가 한 묶음으로 저장됩니다. 불러와 수정한 뒤 다시 저장하면 새 묶음으로 추가됩니다.

보관함의 자료는 브라우저 저장 공간(localStorage)에만 저장됩니다. 브라우저 데이터 삭제 시 없어질 수 있으니 백업/복원 → 전체 JSON 백업을 이용하세요.

백업 복원하기

6.5 전체 JSON 백업을 복원하면 이 브라우저의 상품·콘텐츠·판매 기록이 모두 교체됩니다. 이전 6.4 이하 JSON 백업(판매 기록만 포함)은 판매 기록만 교체하며 보관함은 유지합니다. 먼저 새 백업을 받아 두세요.

기존 AutoBiz CSV 불러오기

이전 Colab 버전에서 다운로드한 CSV 중 상품명, 수량, 매출, 예상 이익 형식의 파일을 가져올 수 있습니다. 새로 가져온 기록은 기존 기록 뒤에 추가됩니다.

CSV는 단순 형식의 파일만 지원합니다. 복잡한 따옴표·줄바꿈 데이터는 JSON 백업을 권장합니다.
