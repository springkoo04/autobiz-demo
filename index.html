데이터 백업 및 복원

기기 간 이동은 파일로

파일 내려받기

입력 데이터는 브라우저에 자동 저장됩니다. 기기를 바꾸거나 브라우저 데이터를 지울 때를 대비해 JSON 파일을 별도로 내려받으세요.

상품·콘텐츠·판매 기록을 하나의 JSON 파일로 백업하거나 판매 기록만 CSV로 내보낼 수 있어요.

백업 복원하기

6.5~7.0 Beta 전체 JSON 백업을 복원하면 이 브라우저의 상품·콘텐츠·판매 기록이 모두 교체됩니다. 이전 6.4 이하 JSON 백업(판매 기록만 포함)은 판매 기록만 교체하며 보관함은 유지합니다. 먼저 새 백업을 받아 두세요.

기존 AutoBiz CSV 불러오기

이전 Colab 버전에서 다운로드한 CSV 중 상품명, 수량, 매출, 예상 이익 형식의 파일을 가져올 수 있습니다. 새로 가져온 기록은 기존 기록 뒤에 추가됩니다.

CSV는 단순 형식의 파일만 지원합니다. 복잡한 따옴표·줄바꿈 데이터는 JSON 백업을 권장합니다.

테스트 버전 이용 안내 · 저장 방식 및 AI 기능
상품·콘텐츠·판매 데이터는 이 브라우저에만 저장되며 다른 기기와 자동 동기화되지 않습니다. AI 문체 추천은 WebGPU 지원 기기에서만 가능하며 최초 모델 다운로드에 많은 데이터와 메모리가 필요할 수 있습니다. 게시용 문구는 AI 원문을 그대로 사용하지 않고 입력 정보와 정해진 문장으로 구성합니다. 입력한 사실 자체는 직접 검토하세요. 로그인·결제 기능은 없고 실제 고객 정보는 입력하지 마세요. AutoBiz 7.0 Beta는 32개 직업·업무 유형의 가상 데이터를 이용한 기능 검증용이며 실제 사용자 검증을 대체하지 않습니다.
